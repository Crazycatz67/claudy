# Claudy build kit: start here

1. Move this `claudy` folder to `~/Developer/claudy`.
2. Do Stage A first: open `brain/README.md` and follow it. No app needed.
3. When Claude can see through your phone, open `docs/PHASES.md` and do Phase 0,
   then paste the Phase B1 prompt into Claude Code (Opus 5.5).

What each file is for:

- `CLAUDE.md`: the rules Claude Code reads automatically every session.
- `docs/FEATURES.md`: every feature, with an ID and a test.
- `docs/PROTOCOL.md`: the messages the phone and Mac send each other.
- `docs/PHASES.md`: the build order, with a prompt to paste for each phase.
- `brain/`: the Mac program (Stage A), already written.
